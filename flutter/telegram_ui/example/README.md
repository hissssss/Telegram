# telegram_ui_example

The gallery app for the `telegram_ui` package: a DialogsActivity-style tabs
demo (glass tab bar, app bar, dialog/user cells, bulletins, bottom sheet), a
liquid-glass playground with live sliders for the refraction parameters and
tier switching, and a browser for the bundled `.attheme` palettes. Run with
`flutter run` from this directory — the liquid tier needs a real device with
Impeller (`ImageFilter.shader`); other backends fall back to frosted.
